# ЕКСПЕРИМЕНТ F – ОПТИМИЗАЦИЈА И ФИНАЛНА СПОРЕДБА НА МОДЕЛИ

## Цел на експериментот

Целта на Experiment F е подобрување и споредба на перформансите на моделите за класификација на тениски удари преку оптимизација на нивните хиперпараметри.

Во експериментот се анализираат три класични алгоритми за машинско учење: Random Forest, Support Vector Machine (SVM) и Gradient Boosting. За секој модел се испитуваат различни комбинации на хиперпараметри со цел да се пронајде конфигурацијата што постигнува најдобар резултат според Macro F1-score.

Потоа, оптимизираните модели се споредуваат со претходно развиените модели од Experiment E, вклучувајќи го и 1D Convolutional Neural Network (1D CNN).

За сите модели се користи истата поделба на податоците од Experiment E1, со цел резултатите да бидат меѓусебно споредливи.

---

## F1 – Оптимизација на Random Forest

Во првиот дел од експериментот беше извршена оптимизација на моделот Random Forest со помош на GridSearchCV.

Беа испитани различни комбинации на следните хиперпараметри:
- `n_estimators` – број на дрвја во моделот;
- `max_depth` – максимална длабочина на дрвјата;
- `max_features` – број на карактеристики што се разгледуваат при поделба;
- `min_samples_split` – минимален број примероци потребни за поделба на јазол;
- `min_samples_leaf` – минимален број примероци во лист;
- `class_weight` – тежинско балансирање на класите.

Оптимизацијата беше извршена со 5-fold Stratified Cross-Validation, при што како критериум за избор беше користен Macro F1-score.

**Најдобра конфигурација:**
- `n_estimators = 200`
- `max_depth = None`
- `max_features = sqrt`
- `min_samples_leaf = 1`
- `min_samples_split = 2`
- `class_weight = balanced`

**Резултати:**

- Најдобар CV Macro F1: 99.17%
- Validation Accuracy: 98.67%
- Validation Macro F1: 98.73%
- Test Accuracy: 98.67%
- Test Macro F1: 98.73%

Оптимизираниот Random Forest постигна високи и еднакви резултати на Validation и Test сетовите.

---

## F2 – Оптимизација на Support Vector Machine (SVM)

Во вториот дел беше извршена оптимизација на SVM моделот.

Беа испитани линеарно и RBF јадро, како и различни вредности за параметарот `C` и параметарот `gamma` кај RBF конфигурацијата.

За оптимизацијата повторно беше користен GridSearchCV со 5-fold Stratified Cross-Validation и Macro F1-score како критериум за избор.

**Најдобра конфигурација:**
- `kernel = rbf`
- `C = 10`
- `gamma = scale`
- `class_weight = balanced`

**Резултати:**

- Најдобар CV Macro F1: 98.92%
- Validation Accuracy: 98.67%
- Validation Macro F1: 98.73%
- Test Accuracy: 96.00%
- Test Macro F1: 96.31%

Иако моделот постигна високи резултати при валидацијата, неговите перформанси на Test сетот беа пониски. Ова укажува дека добрите резултати на Validation сетот не мора секогаш да се пренесат со ист интензитет и на независниот Test сет.

---

## F3 – Оптимизација на Gradient Boosting

Во третиот дел беше извршена оптимизација на Gradient Boosting моделот.

Беа испитани различни вредности за:
- `n_estimators` – број на boosting итерации;
- `learning_rate` – стапка на учење;
- `max_depth` – максимална длабочина на дрвјата;
- `min_samples_split` – минимален број примероци за поделба;
- `min_samples_leaf` – минимален број примероци во лист;
- `subsample` – дел од примероците што се користат при секоја итерација.

Оптимизацијата беше извршена со 5-fold Stratified Cross-Validation, при што беа разгледани 648 комбинации на хиперпараметри.

**Најдобра конфигурација:**
- `n_estimators = 150`
- `learning_rate = 0.05`
- `max_depth = 3`
- `min_samples_leaf = 2`
- `min_samples_split = 10`
- `subsample = 0.8`

**Резултати:**

- Најдобар CV Macro F1: 99.17%
- Validation Accuracy: 98.67%
- Validation Macro F1: 98.73%
- Test Accuracy: 97.33%
- Test Macro F1: 97.50%

Оптимизираниот Gradient Boosting постигна добри резултати, но неговите перформанси на Test сетот беа пониски од оние на Random Forest и 1D CNN.

## F4 – Финална споредба на моделите

Во последниот дел од Experiment F беше извршена финална споредба на основните и оптимизираните модели, заедно со 1D CNN од Experiment E4.

Беа споредени следните модели:
1. Random Forest – основна верзија;
2. SVM – основна верзија;
3. Gradient Boosting – основна верзија;
4. 1D CNN;
5. Random Forest – оптимизирана верзија;
6. SVM – оптимизирана верзија;
7. Gradient Boosting – оптимизирана верзија.

Изборот на модел според Validation резултатите беше направен врз основа на Macro F1-score. Test резултатите беа прикажани одделно и не беа користени за избор на модел.

### Споредба на резултатите

| Модел | Validation Macro F1 | Test Accuracy | Test Macro F1 |
|---|---:|---:|---:|
| Random Forest – основен | 98.73% | 98.67% | 98.73% |
| SVM – основен | 98.73% | Нема податок | Нема податок |
| Gradient Boosting – основен | 97.41% | Нема податок | Нема податок |
| 1D CNN | 100.00% | 98.67% | 98.73% |
| Random Forest – оптимизиран | 98.73% | 98.67% | 98.73% |
| SVM – оптимизиран | 98.73% | 96.00% | 96.31% |
| Gradient Boosting – оптимизиран | 98.73% | 97.33% | 97.50% |

Забелешка: За основните SVM и Gradient Boosting модели не беа достапни Test метрики во зачуваниот резултат од Experiment E3.

### Анализа на резултатите

1D CNN постигна највисок Validation Macro F1-score од 100%. Сепак, на Test сетот постигна Macro F1-score од 98.73%.

Random Forest во основната и оптимизираната верзија постигна исти резултати на Test сетот како 1D CNN:
- Accuracy: 98.67%;
- Macro Precision: 99.19%;
- Macro Recall: 98.33%;
- Macro F1: 98.73%.

Оптимизираниот Gradient Boosting постигна Test Macro F1 од 97.50%, додека оптимизираниот SVM постигна 96.31%.

Врз основа на добиените резултати, не може да се утврди јасна предност на 1D CNN во однос на Random Forest, бидејќи двата модела постигнаа идентични перформанси на Test сетот.

### Заклучок од Experiment F

Experiment F овозможи оптимизација на три класични алгоритми за машинско учење и нивна споредба со претходно развиените модели.

Оптимизацијата покажа дека Random Forest и Gradient Boosting можат да постигнат висок Macro F1-score во текот на вкрстената валидација. Од друга страна, SVM покажа поголема разлика помеѓу Validation и Test резултатите.

Највисок Validation резултат постигна 1D CNN, додека на Test сетот 1D CNN и двете верзии на Random Forest постигнаа идентични резултати.

Сепак, добиените резултати треба да се толкуваат внимателно поради ограничувањата на SmartStrike датасетот идентификувани во Experiment D, особено поврзаноста помеѓу датумот на снимање и класите на активност. Поради тоа, високите резултати не претставуваат доказ за генерализација на нови, досега невидени сесии на снимање.

Experiment F претставува основа за следниот Experiment G, во кој ќе се анализира интерпретабилноста на моделите и влијанието на сензорските карактеристики врз нивните предвидувања.
